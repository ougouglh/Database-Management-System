# 部署配置指南

## 一、配置文件设置

### 1. 创建配置文件

项目使用 `config.yaml` 存储敏感配置信息（数据库密码、JWT密钥等）。

**步骤：**
```bash
# 1. 复制模板文件
cp config.yaml.example config.yaml

# 2. 编辑 config.yaml，填写真实配置值
```

### 2. 生成 JWT Secret Key

**方法一：使用生成脚本（推荐）**
```bash
python generate_key.py
```

**方法二：使用 Python 命令**
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

**方法三：使用 Python 交互**
```python
>>> import secrets
>>> secrets.token_urlsafe(32)
'8K4zJ9nX2pQ7mV5tR3wY1aB6cD8eF0gH'
```

### 3. 填写 config.yaml

```yaml
# MySQL 数据库配置
mysql1:
  host: 192.168.239.131        # 数据库地址
  port: 3306                    # 端口
  user: root                    # 用户名
  password: your_password       # 数据库密码
  database: bigdata_main_data2  # 数据库名
  charset: utf8mb4

# JWT 认证配置
auth:
  secret_key: "8K4zJ9nX2pQ7mV5tR3wY1aB6cD8eF0gH"  # 运行 generate_key.py 生成
  algorithm: "HS256"
  access_token_expire_minutes: 480
```

## 二、安全注意事项

### ⚠️ 重要：不要提交敏感信息到代码仓库

**以下文件必须加入 .gitignore：**
```
config.yaml
.env
*.key
*.pem
```

**.gitignore 配置示例：**
```gitignore
# 敏感配置文件
config.yaml
.env

# Python
__pycache__/
*.pyc
*.pyo
*.pyd

# Vue/Node
frontend/node_modules/
frontend/dist/

# 导出文件
static/exports/

# 日志
logs/
*.log
```

### 密钥备份建议

1. **团队共享：** 使用安全的密码管理器（如 1Password、Bitwarden）
2. **服务器部署：** 将 `config.yaml` 保存在服务器安全目录
3. **定期轮换：** 建议每 6 个月更换一次 JWT Secret Key

## 三、部署检查清单

部署前请确认：

- [ ] 已创建 `config.yaml` 并填写真实配置
- [ ] 已运行 `generate_key.py` 生成新的 JWT Secret Key
- [ ] `config.yaml` 已加入 `.gitignore`
- [ ] 测试数据库连接是否正常
- [ ] 测试登录功能是否正常
- [ ] 确认防火墙已开放相应端口（默认 11219）

## 四、启动服务

### Windows
```bash
# 方式一：使用批处理文件
start_server.bat

# 方式二：直接运行
python app.py
```

### Linux/Mac
```bash
# 方式一：使用脚本
chmod +x start_server.sh
./start_server.sh

# 方式二：直接运行
python app.py
```

### 使用 uvicorn
```bash
uvicorn app:app --host 0.0.0.0 --port 11219
```

## 六、常见问题

### Q1: 启动报错 "config.yaml not found"
**A:** 请先复制 `config.yaml.example` 为 `config.yaml`

### Q2: 登录后提示 "无效的认证令牌"
**A:** 检查 `config.yaml` 中的 `auth.secret_key` 是否正确配置

### Q3: 数据库连接失败
**A:** 检查 `config.yaml` 中的数据库配置是否正确
