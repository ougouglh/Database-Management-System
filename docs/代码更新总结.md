### 一、安全性改进

| 敏感文件保护 | ✅ | .gitignore 配置完成 |

### 二、新增 API

| API | 路径 | 说明 |
|-----|------|------|
| 获取阶段列表 | `GET /api/stages` | 获取所有启用的阶段配置 |
| 获取阶段统计 | `GET /api/stages/{id}/stats` | 获取指定阶段的数据统计 |
| 校验导入文件 | `POST /api/stages/{id}/validate` | 校验上传文件的格式和内容 |
| 预览导入变更 | `POST /api/stages/{id}/preview` | 预览新增/更新/跳过的记录 |
| 执行导入 | `POST /api/stages/{id}/import` | 执行数据导入并记录日志 |
| 获取操作日志 | `GET /api/logs/operations` | 分页获取操作日志 |
| 获取日志统计 | `GET /api/logs/stats` | 获取操作统计信息 |
