### 2. 后端启动问题修复

**问题**: `ModuleNotFoundError: No module named 'api.stage'`

**原因**: `app.py` 中导入了不存在的 `api.stage` 模块（遗留代码）

**修复**: 删除 `app.py` 第57-62行的 `from api.stage import router as stage_router` 和 `app.include_router(stage_router)`

**文件**: `app.py` 第55-59行

### 3. 登录转圈问题排查

**现象**: 点击登录按钮后一直转圈，后端终端无请求日志

**排查过程**:
- 数据库连接测试正常（`pymysql.connect` 可以连通 MySQL）
- 后端服务成功启动（`Application startup complete`）
- `curl` / `requests` 测试发现 `localhost` 解析失败，但 `127.0.0.1` 也失败
- `netstat -ano | findstr 11219` 确认端口在监听

**根本原因**: vite proxy 配置中 `target: 'http://localhost:11219'`，而 Trae IDE 终端环境中 `localhost` 解析异常

**修复**: `frontend/vite.config.js` 中将 proxy target 从 `http://localhost:11219` 改为 `http://127.0.0.1:11219`

**文件**: `frontend/vite.config.js` 第15行

### 4. 表选择下拉框显示异常

**现象**: 导出页面和筛选导出页面的"选择表"下拉框只显示一行，内容异常

**原因**: 后端 `/api/tables` 返回格式为 `{"success": true, "tables": [...]}` ，但前端代码直接把响应对象当数组用了

**修复**:
- `ExportPage.vue` 第148行: `tables.value = res.tables || res || []`
- `FilterExport.vue` 第189行: `tables.value = res.tables || res || []`

**文件**:
- `frontend/src/views/ExportPage.vue` 第148行
- `frontend/src/views/FilterExport.vue` 第189行

### 5. Content-Type charset 修复

**修复**: `frontend/src/api/index.js` 第10行，`Content-Type` 从 `'application/json'` 改为 `'application/json; charset=utf-8'`

**文件**: `frontend/src/api/index.js` 第10行

### 6. LogPage.vue 日志导出功能补全

## 重要决策和理由

1. **删除 `api.stage` 导入**: 该模块不存在于 `api/` 目录中，是旧代码遗留，删除后不影响功能
2. **vite proxy 改用 127.0.0.1**: Trae IDE 环境下 localhost 解析异常，改用 IP 确保代理正确
3. **`res.tables || res || []` 兼容写法**: 兼容后端返回 `{tables: []}` 和直接返回 `[]` 两种格式
4. **日志导出采用 blob 下载**: 与 ExportPage/FilterExport 保持一致的导出模式
